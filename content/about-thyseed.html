平台简介

申创集团（品牌简称世喜 / thyseed）AI 中心面向集团内各业务部门，提供统一的 AI 能力接入与 Token 配额管理服务。通过本系统，管理员可按部门、岗位或项目分配使用额度，员工在授权范围内调用大模型完成日常办公、研发协作与业务创新，实现能力共享、成本可控、使用可审计。

  • 统一网关：对接多种主流大模型与工具能力
  • 配额管理：按部门分配 Token，用量透明可查
  • 安全合规：集团内网使用，行为留痕、权限分级
  • 高效协作：降低各部门单独采购与对接成本

适用对象

本平台的 API Key / Token 仅发放给申创集团及下属单位经审批的正式员工与授权合作方，用于与工作相关的正当业务场景。请勿将账号、密钥转借他人或用于个人非公务用途。

使用规范与禁止事项

使用本 AI 平台时，须严格遵守国家法律法规、集团规章制度及信息安全要求。严禁利用本平台从事或协助下列行为：

  • 搜索、生成、传播色情、淫秽等违法违规内容
  • 涉及赌博及相关违法活动的信息查询与内容生成
  • 涉及毒品制作、交易、滥用等违法信息
  • 歪曲、煽动或传播不当政治言论及敏感有害信息
  • 侵犯他人隐私、知识产权、商业秘密及其他合法权益
  • 利用 AI 进行欺诈、造谣、恶意攻击、绕过安全策略等任何违规或危害集团利益的行为

系统可能对异常调用进行监测与限制。一经发现违规使用，集团有权暂停或收回配额、追究相关责任，并依法配合监管要求处理。

数据与保密

请勿向模型提交未脱敏的客户隐私、财务机密、未公开商业计划等敏感数据。涉及核心商密的内容，请按集团信息安全规定审批后使用，并优先选择经集团认可的安全调用方式。
